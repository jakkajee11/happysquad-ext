# happysquad-ext

Pieces cut from `happysquad` core during the v1.0 rewrite, per [`docs/spec/v1-rewrite.md` §2.1](../happysquad/docs/spec/v1-rewrite.md) in the `happysquad` repo: external executors (glm/opencode), team assembly, ask-kilo, and the requirement/standard specialist reviewers. None of this is wired to the v1 `hs` engine — it's parked here until (or unless) it gets ported.
